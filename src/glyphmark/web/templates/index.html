GlyphMark — what this is

      

    
Text watermarking exploits the gap between rendered glyphs and code points: a
      payload can ride inside a string without changing what a reader sees. This lab lets you write a
      mark, prove it is there, and destroy it — in the same session, from either interface.

Reading a detection report

    
    
      
  • watermark-confirmed — a GlyphMark frame was recovered: magic byte and CRC32 both valid.
    • 
      
  • high-risk / suspicious — heuristics only: invisible code points, confusables, mixed
        scripts or NFKC drift. Third-party marks look like this.
    • 
      
  • The Plane-14 mirror line decodes tag-block code points back to ASCII — that is how
        hidden-instruction injection becomes visible.
    • 
    


    
Choosing a channel

    
    
      
  • Capacity: vs-bytes (1 byte per anchor) and tags (6 bits/char) carry most.
    • 
      
  • Survival: homoglyph outlives paste/JSON/social filters; zero-widths die first.
    • 
      
  • Detectability: everything here is caught by Sanitize — that is the point.

Etiquette

    
Undisclosed watermarking of other people’s text is covert data collection. Character-level marks
      also break exact matching, search and dedup — the same property that makes homograph phishing work.
